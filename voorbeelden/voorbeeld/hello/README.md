# Voorbeeld: Hello

Klein JVM-Kotlinproject om de include vanuit de studentensite en de CI-compile te bewijzen. Geen lesinhoud.

Compileren (via de mise-tools in de wortel van de repo):

    mise run compile

`src/main/kotlin/voorbeeld/Hello.kt` bevat de region `greeting`. De voorbeeldhandout (mdBook) en het dummy-deck (Slidev) tonen dat fragment. Zie `docs/docent/werkwijze.md` voor de regels.
